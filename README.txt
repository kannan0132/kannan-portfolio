KANNAN A — PORTFOLIO WEBSITE

HOW TO VIEW
1. Extract the ZIP file.
2. Open index.html in a modern browser.

FILES
- index.html: website content and page structure
- styles.css: responsive visual design, animations, and layout
- script.js: mobile navigation, rotating role text, and scroll reveals
- assets/kannan-profile.jpg: supplied profile photo
- assets/Kannan-A-Resume.pdf: supplied résumé for download

CUSTOMIZATION NOTES
- The résumé did not include actual LinkedIn or portfolio URLs, so no placeholder social links were invented.
- Contact details and portfolio content are based on the supplied résumé.
- For publishing, upload the extracted folder to Netlify, Vercel, or GitHub Pages.
